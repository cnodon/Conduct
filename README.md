## 你可以用 Conduct 做什么

### Skills 主界面
- 查看多 CLI 的 Skills 实际生效路径与层级
- 在不同 CLI 之间复刻技能

### Skills Marketplace
- 在官方 Skills 聚合仓库中浏览并安装技能
- 添加你喜欢的 Skills Repo URL，自动解析并更新 Skills 列表

### 更新
- 在设置页快速检查版本更新
- 发现新版本后引导 GitHub 下载，支持展示 Release Notes

## 开箱即用（macOS）
1. 在 https://tokenlabs.cn/download.html 查看最新版本与更新说明
2. 从 GitHub 仓库下载最新的 `.dmg` 文件（当前版本：v0.9.5）
3. 首次打开如有系统安全提示，请在系统设置中允许打开
